# AdPromoter AI — AI Powered Advertisement Management SaaS Platform

AdPromoter AI is a modern full-stack MERN SaaS application designed to help businesses create, manage, and optimize advertising campaigns across multiple platforms from one unified dashboard.

The platform now includes powerful AI capabilities powered by Google Gemini AI, allowing users to instantly generate intelligent ad campaigns with AI-generated titles, descriptions, CTAs, hashtags, SEO keywords, smart recommendations, and quality scoring.

# 📦 Getting Started

## 1. Prerequisites

* Node.js (v16 or higher)
* MongoDB Atlas or Local MongoDB
* Cloudinary Account
* Google Gemini API Key

---

# 🔑 Environment Variables

## Backend (.env)

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key

FRONTEND_URL=http://localhost:5173
ADMIN_URL=http://localhost:5174

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

GEMINI_API_KEY=your_gemini_api_key

---

## Frontend (.env)

VITE_API_URL=http://localhost:5000/api

---

## Admin (.env)

VITE_API_URL=http://localhost:5000/api
